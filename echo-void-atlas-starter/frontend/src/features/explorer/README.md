# Global Explorer

Export `GlobalExplorer` from `index.tsx` with the shared `ExplorerProps` interface. The feature owns the Leaflet map, marker selection, filters, candidate list and data-availability details. It never calculates analog scores or changes scientific data.

Use the Explorer route to try the supplied five-site fixture. `npm test` in frontend runs its DOM interaction tests. See `docs/TASK_B_HANDOFF.md` for sources, network behavior and limitations.
