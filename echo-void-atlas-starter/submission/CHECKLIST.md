# Submission and Demo Checklist

- [ ] NASA source/resource actually used (not only hyperlinked) and documented in final submission.
- [ ] ≥1 verified comparison with ≥2 Earth candidates and ≥3 comparable terrain variables, or honestly disclose unavailable parts.
- [ ] Moon/Mars modes accurately label data readiness; no fabricated measurements.
- [ ] Drone clearly marked EARTH-BASED SIMULATION; procedural assets clearly identified.
- [ ] Public website, repository/demo links tested in incognito and on another device.
- [ ] Video ≤30 seconds OR slide presentation ≤7 slides; keep a back-up demo.
- [ ] AI-assisted code/data described; AI-generated images/video visibly labeled per submission guidance.
- [ ] No NASA branding/logos in generated assets unless rights permit.
- [ ] English submission; citations and limitations accessible.
- [ ] NASA project page saved AND final 'Submit for Judging' action confirmed.
- [ ] Confirm local event cutoff (may differ from global 2026-11-15 23:59 local-event deadline).
