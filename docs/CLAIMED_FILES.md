# What is immediately ready vs still missing

**Ready in starter:** TypeScript contracts, 3 JSON schemas, candidate/target metadata fixtures, test procedural height grid, navigation/context, five placeholder screens, task rules and integration docs.

**NOT yet implemented:** actual Leaflet map; Python scoring engine; NASA DEM downloading/processing; true terrain comparison, usable Three.js drone; integrated report charts; live API; PDF export; submission video.

The starter deliberately refuses to display fabricated NASA numbers. Contributors deliver these via Tasks B–F.
