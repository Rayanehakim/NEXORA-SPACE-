# Locally reproduced Askja–Moon trial

These records identify the five supplied raster files and preserve the actual processing outputs. They are **provisional**, not a reviewed scientific release. Original release verification and independent study-window review remain pending.

- `study.json`: explicit centers, metric grid and roughness settings.
- `sources.json`: raw-file hashes, coordinate systems, dimensions and source references.
- `scenarios.json`: descriptors, prepared-file hashes and lunar quality checks for all five processing scenarios.
- `earth-features.json`, `moon-features.json`, `analysis-plan.json`: baseline pipeline outputs for scientific review.
- `provisional-qa.json`: frontend evidence snapshot, including processing versions and code hashes.

Baseline features marked MEASURED describe derivation from supplied rasters; they do not certify source authenticity or publication approval. Do not copy local experimental comparison results into public assets. The release ledger remains empty. See [reproduction instructions](../../../docs/IMPORTED_DATASETS_HANDOFF.md).
